| Tipo                     | Ejemplo                                | Descripción                  |
| ------------------------ | -------------------------------------- | ----------------------------------------- |
| **String**               | `nombre="Carlos Ortiz"`                | Texto, nombre, título, carrera            |
| **Number**               | `semestre={6}`                         | Edad, semestre, precio, cantidad          |
| **Boolean**              | `activo={true}`                        | Activo/inactivo, seleccionado, disponible |
| **Array**                | `materias={["Web", "BD", "IA"]}`       | Listas de datos                           |
| **Object**               | `alumno={{ nombre: "Ana", edad: 21 }}` | Agrupar información relacionada           |
| **Function**             | `onPress={handlePress}`                | Ejecutar una acción desde el componente   |
| **JSX / React element**  | `icon={<Icon />}`                      | Pasar contenido visual al componente      |
| **`null` / `undefined`** | `avatar={null}`                        | Indicar que no existe un dato             |
